<h1>Laporan Praktikum Web Profil IMATIKA Universitas Pancasila</h1>

<h2>Ringkasan Perubahan, Masalah, dan Solusi</h2>
<p>Proses pengembangan halaman web profil IMATIKA Universitas Pancasila berfokus pada penyusunan struktur HTML yang terorganisir dan sistematis. Pada tahap awal, dilakukan perubahan tata letak informasi agar pengakses dapat menavigasi konten secara intuitif, dimulai dari navigasi internal, identitas organisasi, struktur divisi, alur open recruitment, hingga bagian kontak resmi.</p>

<p>Masalah utama yang dihadapi selama proses pembuatan adalah penataan jenis elemen list yang tepat sesuai konteks data, serta pengelolaan tautan navigasi agar bekerja secara presisi tanpa hambatan. Selain itu, memastikan penulisan atribut pada elemen media tetap memenuhi standar aksesibilitas web juga menjadi perhatian utama.</p>

<p>Solusi yang diterapkan adalah menggunakan tiga tipe list HTML secara spesifik: description list (&lt;dl&gt;) untuk rincian data identitas, unordered list (&lt;ul&gt;) untuk daftar divisi organisasi, dan ordered list (&lt;ol&gt;) untuk tahapan alur pendaftaran anggota. Untuk navigasi, digunakan anchor internal yang terhubung langsung ke atribut id pada tiap bagian halaman, dilengkapi tautan external ke situs utama kampus dan tautan mailto untuk komunikasi email. Penambahan atribut alt pada logo dan foto kegiatan juga diterapkan secara lengkap untuk memenuhi seluruh kriteria tugas.</p>
